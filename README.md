# Блиц по истории

Тренажёр к блиц-опросам по истории России: тесты с вариантами ответа.
Каждый блиц-опрос — отдельный тест, темы не смешиваются.

Сайт: https://qmixyd.github.io/blitz/

## Режимы

- **Билет** — как на опросе: 2 даты, 2 термина, 1 личность.
- **Все вопросы**, **только даты / термины / личности**.
- **Работа над ошибками** — вопросы, на которых были ошибки, пока не ответишь верно 2 раза подряд.
- Направление вопросов: как на опросе, обратно или вперемешку.

## Как добавить новый блиц-опрос

- Для всех устройств: опросы лежат в блоке `<script id="quiz-data">` внутри `index.html` —
  новый опрос добавляется туда ещё одним объектом в массиве.
- Только в своём браузере: кнопка «Добавить блиц-опрос из .docx» на сайте.

Прогресс хранится в браузере (localStorage).
